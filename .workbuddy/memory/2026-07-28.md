## desktop sidebar 不显示 Settings 的真正根因
用户重建 dist 后 sidebar 仍是老的「导出 Bundle」无 Settings。
根因：`apps/desktop/package.json` 的 `dev` 脚本是 `pnpm build && electron .`——只 build React 产物，**没启动 vite dev server**，`VITE_DEV_SERVER_URL` 为空，electron/main.ts:81 回退加载 `http://127.0.0.1:3700`（daemon 的 vanilla 客户端 packages/channels/web/public，遗留玻璃拟态 UI，footer 是老的导出 Bundle）。React SPA（带 Settings 的 WorkList）根本没被加载。
- 验证：构建出的 dist 里确实有「设置」(11次) 和「导出 Bundle」(2次，在 SettingsPanel/CommandPalette 里)，说明 React 源码是对的，只是没被 electron 加载
- 修复：`dev` 脚本改为 `vite`（vite-plugin-electron 自动启动 dev server + 拉起 electron + 设 VITE_DEV_SERVER_URL + HMR）；原 build+run 流程保留为 `start`
- 验证：vite dev server 成功启动（VITE v8.1.5 ready，监听 localhost:5175），electron 插件激活
- 用户需重跑 `pnpm dev:desktop`（现在走 vite dev）即可看到 React WorkList 的 Settings 按钮
